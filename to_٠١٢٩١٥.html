إصدارات HTML

  • HTML 1.0 (1991) - الإصدار الأول
  • HTML 2.0 (1995) - الإصدار القياسي الأول
  • HTML 3.2 (1997) - إضافة الجداول والتخطيط
  • HTML 4.01 (1999) - فصل المحتوى عن التنسيق
  • XHTML 1.0 (2000) - HTML بصيغة XML
  • HTML5 (2014) - الإصدار الحالي مع إضافات متعددة
  • HTML5.1 و HTML5.2 - تحديثات على HTML5
  • HTML5.3 (قيد التطوير) - التحديث القادم

عوده لصفحه الرئيسية

<header> دلالي يحدد رأس الصفحة أو القسم رأس الموقع أو المقال
<div> غير دلالي حاوية عامة بدون معنى محدد <div id="header">
<nav> دلالي يحدد روابط التنقل القائمة الرئيسية للموقع
<section> دلالي يحدد قسمًا مستقلًا في المستند فصل في مقال أو قسم محتوى
<span> غير دلالي حاوية سطرية عامة <span class="highlight">
<article> دلالي يحدد محتوى مستقل وقائم بذاته مقالة، تدوينة، تعليق
